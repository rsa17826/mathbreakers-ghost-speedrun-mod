the releases have the game and mod from the releases

download https://github.com/BepInEx/BepInEx/releases/download/v5.4.23.5/BepInEx_win_x86_5.4.23.5.zip and add the BepInEx folder and the winhttp.dll and only those files to the mathbreakers folder then add the mods dlls to ./mathbreakers/BepInEx/plugins/

start the proxy as this game doesn't support newer connections

eg
`node proxy.js 38281 wss://multiworld.gg:8080`

then connect to `127.0.0.1:38281` in the game
